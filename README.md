# SONY SMC-70のテープフォーマットWAVファイルを介してパソコンとファイル交換

SONY SMC-70とパソコンが連携できるようSMC-70で出力されるテープフォーマットWAVファイルとパソコンのAssembler等で出力されるバイナリファイルを相互に変換できるツールを作成しました。

SMC-777ハードウェア解説書を元に解析していますのでSMC-777でも同じように使えるはずですが、CP/MマシンであるSMC-777はFDが基本ですのでCMTを使う場面があまりない気がします。

SONY BASICで作ったプログラムを相互で読み込んで利用する用途には使えると思います。

## 使い方
### SMC70BIN2CMT.exe
　パソコンのAssembler等で出力されるバイナリファイルをSMC-70で読み込めるWAVファイルに変換します。
 
　書式)

　　SMC70BIN2CMT 変換元バイナリファイル名 SMC-70用WAVファイル名 ロード先頭番地 実行先頭番地 FileID CMTファイル名(8文字+拡張子3文字)
 
　　FileIDは後述スタンダードラベルを参照してください。

　例)機械語プログラム

　　SMC70BIN2CMT input.bin output.wav 0100 0100 00 test

　　input.binをロードアドレス$0100、実行アドレス$0100の機械語、CMTファイル名をtestとしてoutput.wavファイルを作成します。

　　機械語ファイル 00:BINARYの時のCMTファイル名は好きにつけて大丈夫です。

　例)BASICプログラム

　　SMC70BIN2CMT input.bin output.wav 0000 0000 01 test

　　input.binをCMTファイル名をtestとしてoutput.wavファイルを作成します。

　　BASICプログラム 01:BASIC Programの時のロードアドレス、実行アドレスは$0000です。BASICからCLOADでLOADするときにCMTファイル名を指定しないとロードできません。ここで指定するCMTファイル名を忘れないようにしてください。
　　

### SMC70CMT2BIN.exe
　SMC-70から出力されるWAVファイルをパソコンでプログラムと認識できるバイナリファイルに変換します。
 
　書式)

　　SMC70CMT2BIN SMC-70用WAVファイル名 変換先バイナリファイル名

　例)

　　SMC70CMT2BIN input.wav output.bin

　　ロード先頭番地、実行先頭番地、FileID、CMTファイル名はバイナリファイルには含まれません。

　　コンソールメッセージとして表示されるのみです。

### SMC70CmtRawDecode.exe
　SMC-70から出力されるWAVファイルをCMTフォーマットのままバイナリファイルに変換します。
 
　CMTフォーマットがどのように記録されているのか見えるように作成しました。

　CMTフォーマットとして出力されるデータのうち、ファイル名などの領域がスタンダードラベルでフォーマットは次のようになっています。(SMC-777ハードウェア解説書による)

#### スタンダードラベル
|バイト長|名前|内容|備考|
| ------------ | ------------ | ------------ | ------------ |
|1|ファイルIDレコード|プログラムのファイル形式を示します||
|||00h:機械語のプログラムファイル||
|||01h:BASICのプログラムファイル||
|||02h:BASICのデータファイル||
|||03h:BASICのリンクモジュール||
|||04h～0Fh:Reserved||
|8|ファイル名|||
|3|タイプ名|||
|2|格納番地|||
|2|実行開始番地|||
|2|データ長|||
|1|コマンドフラグ|||
|13|フリーエリア|||
|1|チェックサム|||
|2|Reserved|00h×2|(注1)|

(注1)SMC-777ハードウェア解説書にはこの2Byteは無いのですが、WAVファイル、ROMの解析から必要と判断しました

　その後ろに実データが記録されます。レコード長は常に128Byte+チェックサム1Byteで元データが128Byte以上の時は128Byte+チェックサム1Byteが複数回繰り返されることになります。

　また、128Byteに満たないレコードは00hで補完され常に128Byteになります。

#### 実データ
|バイト長|名前|内容|備考|
| ------------ | ------------ | ------------ | ------------ |
|128|レコード1|||
|1|チェックサム|||
||(以下繰り返し)|||
|128|レコードn|||
|1|チェックサム|||

　書式)

　　SMC70CmtRawDecode SMC-70用WAVファイル名 変換先バイナリファイル名

　例)

　　SMC70CmtRawDecode input.wav output.bin
